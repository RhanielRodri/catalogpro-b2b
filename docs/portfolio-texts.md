## Workana / Upwork (bloco de portfólio — até 5 linhas)

**CatalogPro B2B** — catálogo digital para empresas que vendem por cotação.
O cliente pesquisa produtos por categoria, marca ou SKU, monta a lista e envia a solicitação diretamente para o time comercial.
A equipe acessa um painel administrativo protegido para acompanhar e responder cada pedido.
Stack: React, Node.js, PostgreSQL, Prisma, autenticação por cookie httpOnly, deploy em Vercel + Render.
Projeto em produção com API real, rate limiting, cache inteligente e layout responsivo.
